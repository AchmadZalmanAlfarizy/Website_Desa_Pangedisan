# Instruksi Penambahan Logo Desa

## Untuk Fitur Download PDF

Agar logo desa muncul pada PDF surat yang dihasilkan, silakan:

1. Siapkan file logo desa dalam format **PNG**
2. Ukuran yang disarankan: **200x200 pixels** atau lebih (persegi)
3. Simpan file logo dengan nama: `logo-desa.png`
4. Letakkan di folder: `public/images/logo-desa.png`

## Contoh Struktur Folder

```
public/
  images/
    logo-desa.png  <-- Letakkan file logo di sini
```

## Catatan

- Jika logo tidak tersedia, PDF tetap akan dibuat tanpa logo (hanya teks kop surat)
- Format file harus PNG untuk hasil terbaik
- Pastikan file tidak terlalu besar (maksimal 500KB)
